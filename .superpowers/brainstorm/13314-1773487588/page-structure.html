Новый порядок секций

Текущий: Hero → Pain/Solution → Flask+Метрики → Отзыв → PumpJack+Направления → Расписание → Форма.
Предлагаю пересобрать воронку. Какой вариант ближе?

A

Воронка "Проблема → Доказательство → Действие"

1. Hero (с лого клиентов)
2. Pain / Solution (split screen)
3. Метрики + Отзывы (2-3 отзыва, без Flask)
4. Направления (6 карточек, кликабельные → фильтр расписания)
5. Расписание (с фильтрами + кнопка "Записаться" → модалка)
6. Корпоративная форма (для заказа под компанию)
— PumpJack: убрать или оставить декором в hero
  • Классическая StoryBrand-воронка
  • Расписание ближе к середине — раньше видят курсы
  • Направления работают как навигация к расписанию
B

Воронка "Экспертиза → Каталог → Доверие"

1. Hero (с лого клиентов)
2. Направления + PumpJack (экспертиза, масштаб)
3. Расписание (с фильтрами + "Записаться")
4. Метрики + Отзывы (после каталога — подкрепляют решение)
5. Pain / Solution (для сомневающихся, дочитавших до конца)
6. Корпоративная форма
  • Каталог сразу после hero — для тех, кто уже готов
  • Доверие подкрепляет после просмотра курсов
  • Pain/Solution внизу — ловит сомневающихся
