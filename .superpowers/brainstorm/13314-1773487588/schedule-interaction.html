Как пользователь должен записываться на курс?

Сейчас: список курсов → "Подробнее" → уход на /schedule. Форма только внизу, отдельно от курсов.

A

Модальная запись на курс

У каждого курса кнопка "Записаться" → открывается модальное окно с формой (имя, телефон, компания). Название курса подставляется автоматически.

  • Минимальное трение — пользователь не уходит со страницы
  • Конкретная заявка: "хочу на курс X"
  • Форма внизу тоже остаётся — для корпоративных запросов
B

Inline-форма в раскрытии курса

Клик по курсу раскрывает accordion с подробностями + форма записи прямо внутри. Без модалок.

  • Всё на одной странице, нативно
  • Больше контекста видно (описание + форма рядом)
  • Может удлинить страницу
C

Общая форма с выбором курса

Одна форма на странице, но с выпадающим списком/чекбоксами курсов. Кнопки "Записаться" у курсов скроллят к этой форме и предзаполняют выбор.

  • Проще в реализации
  • Одна точка конверсии
  • Менее прямолинейно для пользователя
