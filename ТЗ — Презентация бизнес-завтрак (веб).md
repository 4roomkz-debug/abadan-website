**Формат:** Онлайн-сайт со слайдами (горизонтальный скролл)

**Референс:** abadan.kz (горизонтальные секции)

---

## 1. Концепция

Презентация как лендинг со слайдами:
- Горизонтальный скролл (swipe влево-вправо)
- Каждый слайд = полный экран
- Минималистичный дизайн
- Можно показывать на проекторе
- Можно открыть на телефоне (участники)

## 5. Функциональность

### Навигация

- Стрелки влево/вправо на клавиатуре
- Свайп на мобильных
- Клик по стрелкам на экране
- Индикатор прогресса (точки внизу)

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `→` или `Space` | Следующий слайд |
| `←` | Предыдущий слайд |
| `Home` | Первый слайд |
| `End` | Последний слайд |
| `F` | Полноэкранный режим |
| `Esc` | Выход из полноэкранного |

### Режимы

1. **Presenter mode** (для проектора) — полный экран
2. **Viewer mode** (для участников) — с навигацией

## 7. Пример кода

### Главная страница (app/page.tsx)

```tsx
'use client'

import { useState, useEffect } from 'react'
import { motion, AnimatePresence } from 'framer-motion'
import { slides } from '@/data/slides'
import ProgressDots from '@/components/ProgressDots'

export default function Presentation() {
  const [currentSlide, setCurrentSlide] = useState(0)

  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'ArrowRight' || e.key === ' ') {
        setCurrentSlide(prev => Math.min(prev + 1, slides.length - 1))
      } else if (e.key === 'ArrowLeft') {
        setCurrentSlide(prev => Math.max(prev - 1, 0))
      } else if (e.key === 'f') {
        document.documentElement.requestFullscreen()
      }
    }
    window.addEventListener('keydown', handleKeyDown)
    return () => window.removeEventListener('keydown', handleKeyDown)
  }, [])

  return (
    <main className="h-screen w-screen bg-[#0a0a0a] overflow-hidden">
      <AnimatePresence mode="wait">
        <motion.div
          key={currentSlide}
          initial={{ opacity: 0, x: 100 }}
          animate={{ opacity: 1, x: 0 }}
          exit={{ opacity: 0, x: -100 }}
          transition={{ duration: 0.3 }}
          className="h-full w-full flex items-center justify-center"
        >
          {slides[currentSlide].component}
        </motion.div>
      </AnimatePresence>

      <ProgressDots
        total={slides.length}
        current={currentSlide}
        onChange={setCurrentSlide}
      />
    </main>
  )
}
```
